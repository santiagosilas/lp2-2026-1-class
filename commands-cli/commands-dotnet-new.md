Ver TODOS os templates disponíveis

```shell
dotnet new list
```

App de linha de comando (console)

```shell
dotnet new console -o MeuConsole
```

classlib - Biblioteca de classes (.dll)

```shell
dotnet new classlib -o MinhaLib
```

xunit

```shell
dotnet new xunit -o TestesXunit
```

web (ASP.NET Core Empty) - App web mínima (sem MVC, Razor, etc)

```shell
dotnet new web -o MeuWebApp
```

webapi - API REST com controllers

```shell
dotnet new webapi -o MinhaApi
```

mvc (ASP.NET Core MVC (Controllers + Views))

```shell
dotnet new mvc -o MeuMvc
```

razor - Razor Pages (alternativa ao MVC).ss

```shell
dotnet new razor -o MeuRazor
```

sln (solution)

```shell
dotnet new sln -n MinhaSolucao
```
